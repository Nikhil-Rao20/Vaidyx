## DRUG INTERACTIONS — HIGH-RISK IN INDIA

| Drug Pair | Interaction | Action |
|-----------|------------|--------|
| Warfarin + Fluconazole | CYP2C9 inhibition → INR ↑↑ | Reduce warfarin dose 25–50%; check INR 3–5 days |
| Warfarin + Rifampicin | CYP450 induction → INR ↓↓ | Increase warfarin 2–3× during TB treatment; close monitoring |
| Warfarin + Azithromycin | P-gp inhibition → INR ↑ | Monitor INR after 3 days |
| Metformin + IV Contrast | Lactic acidosis risk | Hold metformin 48h before contrast; resume when CrCl confirmed stable |
| Methotrexate + NSAIDs | Reduced MTX clearance → toxicity | AVOID concurrent use |
| Digoxin + Amiodarone | Amiodarone ↑ digoxin levels | Reduce digoxin dose 50%; monitor levels |
| Simvastatin + Clarithromycin | CYP3A4 inhibition → myopathy | Switch to pravastatin during clarithromycin course |
| Atorvastatin + Fluconazole | CYP3A4 inhibition | Temporary statin hold if azole course <2 weeks |
| Theophylline + Ciprofloxacin | CYP1A2 inhibition → theophylline toxicity | Reduce theophylline 50%; check levels |
| Phenytoin + Rifampicin | Rifampicin induces phenytoin → sub-therapeutic | Increase phenytoin dose; monitor levels |
| Phenytoin + Metronidazole | Inhibits phenytoin metabolism | Reduce phenytoin; check levels |
| ACE inhibitor + K-sparing diuretic | Hyperkalaemia | Monitor K+ weekly |
| Carbamazepine + Erythromycin | ↑ Carbamazepine levels → toxicity | AVOID; use azithromycin instead |
| Haloperidol + Metoclopramide | Additive extrapyramidal effects | Monitor EPS; avoid combination if possible |
