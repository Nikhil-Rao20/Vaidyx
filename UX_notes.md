6) Affordance and signifiers, making the user understand the things by default by the design that explictly mentioning, like hovering, tool tips, etc or anything

9) adjust the line spacing and letter spacing to make it look interesting properly
10) use colour theory, use colours signifiers to get attention, use colour for purpose
11) use the shadows and blur to make good 3d effect like the background box should have lighter shadows and the box in the box should have stronger shadow
