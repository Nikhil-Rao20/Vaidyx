Your files: his_mock/dicom_studies.py, his_mock/build.py (only the image-source switch and its CLI flag), his_mock/ui.py or the radiology module footer (credit line), his_mock/tests/test_dicom.py (+ a new test file for the switch), pacs_public/** (if a fix is needed), data/his_mock/dicom (rebuilt), the Orthanc database (through its REST API only: delete our studies and upload again). 1. Image-source switch in dicom_studies.build_all (and the per-study builder the desk uses when a study is reported live): when pacs_public/assignment.json maps the study's accession, copy and relabel that public series (relabel.relabel_series with the HIMS identity, the study UID from ids.study_uid(accession), series/instance UID functions from the his_mock conventions, the accession, the HIMS study date and time, InstitutionName "Vaidyx Demo Hospital", the referring doctor, the test label as StudyDescription) into dicom/<accession slug>/ instead of generating synthetic pixels; record on the imaging study "image_source": {"kind": "public", "collection", "licence", "doi", "source_series_uid"} or {"kind": "synthetic"}; verify with relabel.verify_relabelled. 2. 4. Tests: the switch with a tiny synthetic "public" library made in a temp dir (never real downloaded files), the fallback when the library is missing, image_source recorded, verify_relabelled run. Run `/data/vaidyx/venv/app/bin/python -m pytest his_mock/tests pacs_public/tests -q` until green, and the conformance check `python -m his_mock.eval.conformance --data data/his_mock`.
