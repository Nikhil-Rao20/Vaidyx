# Vaidyx-TB backend map (18 Oct 2026, Explore agent)

Code: routes/tumour_board_routes.py and tumour_board/*.py. Data root data/tumour_board/ (config.DATA_ROOT, override TB_DATA_ROOT).

## Conventions
- All paths start with /api/tb. Router from setup_tumour_board_routes(), mounted in app.py. Every route needs a Vaidyx login (cookie). Route class _ModelErrorRoute: a login with the TB disabled flag gets 403; any path under /cases, /sessions, /intake, /metrics needs can(read_case) (placed somewhere); any /cases/{id}/... (except /cases/from-his) runs access.scope(): none -> 403; REQUESTS scope may only call GET /cases/{id}, GET documents/{doc}(/file), POST documents/{doc}/images, POST requests/{a}/acknowledge|done, POST actions/{a}(/close|/dismiss-suggestion); llm.LLMError -> 502.
- Shorthand: login = any logged-in user; known = _need_known (Vaidyx admin, or placed and not disabled); can(x) = org.require; may(x) = access.require (can plus the owner rule); job = ingestion job id, poll GET /jobs/{id}.
