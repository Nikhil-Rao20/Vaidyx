# his_mock map: the mock Indian hospital (SYNTHETIC) (18 Oct 2026, Explore agent)

Code his_mock/. Data data/his_mock/. README his_mock/README.md (partly outdated, see 0).

## 0. README vs code
- FHIR token only in the header Authorization: Bearer (query token gets 401). No Vaidyx proxy for the human screens (/his, /desk, /view are opened directly on :7130; only /api/tb/pacs/{path} is proxied). DICOM built only for performed studies (order completed); registered until uploaded. No registrations/documents/referrals tables: each patient record is one registration; documents in reports[].versions[].document; referrals in encounters[].referrals. No order entry on the screens (model.place_order only from generator.py). Live store is post-demo (P19 radiology reports signed final v2 on 14 Oct); rebuild before his_scenarios.
